# S04b — 맵 화면 전환 (Rusty형 프레젠테이션) ★재미 재검증 (M1)

**선행**: S04 | **기획서 참조**: **2-2장(게임 화면·조작 — 이 세션의 명세)**, 2장(3구역)

## 배경 (방향 전환)
S03~S04의 탭 UI는 기획 의도(Rusty's Retirement형 공간 시뮬레이션)와 달라 디버그 화면으로 강등한다. 코어 로직(Garden/Workshop/Shop/Wallet/시계/세이브 v3)과 테스트 110개는 전부 재사용 — **이 세션은 표현 계층 교체다.**

## In
- **가로형 타일 맵 씬**: 정원(밭 그리드)·공방(작업대)·상점(진열대)이 한 화면의 실제 공간으로 배치 (플레이스홀더 타일 = 색 사각형 + 이모지). 카메라 구도는 미니 모드 대비 가로형
- **커서 지시형 조작**: 밭 클릭 = 심기(종자 팝업)/수확 · 작업대 클릭 = 가공 시작/수령 · 진열대 클릭 = 진열/회수 — 전부 기존 `GameSession` API에 연결 (월드 오브젝트 클릭, 레이캐스트)
- 밭 확장·티어2 해금을 맵 위 상호작용으로 (예: 잠긴 밭 타일 클릭 = 가격 표시 → 구매)
- 식물 성장을 맵 타일 위에서 시각화 (단계별 색/크기 변화 — `displayEmoji` 참조 구조 유지)
- 손님 연출 최소 1종: 판매 발생 시 상점 앞에 손님이 나타났다 사라짐 (본격 유닛 AI는 S09 몫 — 여기선 연출만)
- HUD(시계·골드·창고)는 맵과 분리된 레이어 (미니 모드 대비)
- 기존 `GameScreen` 탭 UI → **디버그 화면으로 강등** (단축키/메뉴로 열기, 삭제 금지 — 이후 세션의 검증 도구)
- 세이브 변경 없음 (표현 계층만)

## Out
견습생 유닛·경로 탐색·작업 AI(S09), 포션/조합 UI(S05~S06), 미니 모드 구현(출시 후 보너스), 정식 아트(A트랙)

## 완료 기준
S04와 동일한 풀 루프(심기→수확→가공→진열→판매→밭 확장→티어2 해금)가 **맵 위 커서 조작만으로** 전부 가능. **★유저 10분 플레이 판정** — "맵을 구경하며 개입하는" 흐름이 재미있는가를 유저가 판정해 PROGRESS에 기록 (통과 전 S05 진행 금지)
