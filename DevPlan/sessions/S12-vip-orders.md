# S12 — VIP 주문 (M5)

**선행**: S10, S11 | **기획서 참조**: 23장(VIP 주문), 26장(시스템 통합)

## 목표
시간 제한 + 큰 보상으로 능동 플레이의 순간 만들기.

## In
- VIP 5종 (귀족/모험가/늙은 마법사/왕족/수상한 그림자), 명성 기반 등장 조건·빈도 (2~4시간, 명성↑ 시 최대 1시간)
- 주문 생성: 플레이어가 해금한 포션 중에서 선정 (해결 불가능한 주문 금지 — 보유 해금 기반 샘플링)
- 제한 시간 타이머 + 알림, 만료 자동 거절 (-5 명성)
- 보상 (배율/희귀 재료/별빛), 수상한 그림자의 도덕적 선택 (탁한 포션 주문 포함)
- 캐릭터 시너지 훅은 데이터 태그로만 (잭스/셰라/세이지 — 실제 발동은 해당 캐릭터 투입 세션에서)
- 날씨·명성 조건 결합 등장 (26장 "비 오는 날 인어" 류)

## Out
절차적 조성 주문 (보너스 콘텐츠 — 구현 안 함)

## 완료 기준
게임 시작 30분 튜토리얼 VIP → 주기 등장 → 완수/만료 흐름 작동
