# S06 — 도감 + 발견 UX (M2)

**선행**: S04, S05 | **기획서 참조**: 6장(도감 구성), 7장(발견·도감 보너스)

## 목표
매칭 엔진에 얼굴을 붙인다 — 자유 투입, 발견의 순간, 영구 진행도.

## In
- 작업대 자유 투입 UI (재료 선택 → 투입 → 결과)
- 발견 연출 ("✨ 새로운 포션 발견!") + 별빛 조각 보상
- 도감 UI: 포션 페이지(미발견 ???), 실험 일지 페이지(실패 부산물), 발견 후 원클릭 재제조
- 도감 완성도 보너스 (25/50/75/100% → 글로벌 골드 +5/15/30/50%) — 실험 일지 포함 집계

## Out
조건부 레시피의 실제 개방(S11 — 지금은 ???로 보임), 전체 데이터 입력(S07)
