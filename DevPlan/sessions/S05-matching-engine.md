# S05 — 조합 매칭 엔진 (M2)

**선행**: S01 (S02~S04와 독립 — 병렬 가능) | **기획서 참조**: 6장(포션 전체), 7장(4단계 매칭 규칙)

## 목표
게임의 심장인 조합 판정을 순수 C# 로직 + 유닛 테스트로. UI 없이 로직만.

## In
- 4단계 판정 파이프라인:
  1. 조성 매칭 — 투입 재료의 조성 합 = 포션 조성
  2. 재료 지정 — 조성 일치해도 지정 재료 미포함 시 실패 + 힌트 반환
  3. 조건 게이트 — 조건 태그(야간/비/일식 등) 확인. 실제 날씨는 S11이 공급 — 여기선 인터페이스로 주입
  4. 실패 부산물 — 최다 투입 원소 분기 (🔥🌍→침전물 / 💧💨→안개병 / 동률·합4↓→탁한 포션), 판매가 = min(표기가, 재료 가치 30%)
- "같은 조성, 다른 조건" 처리 (생명수/약초 케이스)
- Unity Test Runner 유닛 테스트: 33종 전 레시피 + 실패 3분기 + 경계 케이스 (5번째 원소 칸 포함 시 동작도)

## Out
UI/발견 연출(S06), 무지개 수정 와일드카드(보너스 콘텐츠 — 구현 안 함)

## 완료 기준
테스트 전부 그린. 매칭 로직이 MonoBehaviour 비의존 (순수 클래스)
