# S07 — 전체 콘텐츠 데이터 + 경제 검증 (M2)

**선행**: S06 | **기획서 참조**: 4장(식물 20), 5장(재료 15), 6장(포션 33), 8장(경제 곡선·시뮬레이션 표)

## 목표
콘텐츠 전량 투입 + 경제 곡선이 기획서 시뮬레이션과 맞는지 검증.

## In
- SO 데이터 전량 입력: 식물 20 · 재료 15 (2차 정수, 3차 별빛 분말/시간의 모래/무지개 수정) · 포션 30 + 실패 부산물 3
- 가공 체인 2·3차 (정수 추출, 별빛 분말 변환)
- 티어 해금 비용 (`이전 티어 총수입 × 0.1`), 업그레이드 트리 기초
- 치트 콘솔 확장 (골드 지급, 전체 해금, 시간 배속)
- 배속 플레이로 1회차 곡선을 8장 표(0~5h, 600G/h → 30M G/h)와 대조 → 어긋나면 데이터 튜닝, 결과를 PROGRESS.md에 기록

## Out
조건부 포션 개방(S11), 프레스티지(S14)

## 완료 기준
가속 1회차가 기획서 곡선과 대략 일치 (구간별 ±50% 이내). 어긋난 지점과 튜닝 내역 기록
