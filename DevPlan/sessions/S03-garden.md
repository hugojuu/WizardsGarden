# S03 — 정원 구역 (M1)

**선행**: S02 | **기획서 참조**: 2장(게임루프·3구역), 4장(식물 — 티어1만)

## 목표
코어 루프의 첫 조각: 심고 → 기르고 → 수확.

## In
- 밭 슬롯 그리드 (초기 몇 칸), 슬롯 선택 → 종자 심기
- 성장 타이머 (자원 시간 기반 — S02 시계 구독), 성장 단계 표시, 완료 시 수확 가능
- 티어1 식물 4종 (S01 샘플 데이터 활용), 수확물 인벤토리 (기초)
- 최소 UI + 플레이스홀더 아트 규약 (색 사각형 + 이모지)

## Out
가공/판매(S04), 밭 확장 구매(S04), 자동 수확(S08~S09)

## 완료 기준
4종을 심고 수확해 인벤토리에 쌓인다. 성장 시간이 데이터 값(3초/15초)대로 작동
