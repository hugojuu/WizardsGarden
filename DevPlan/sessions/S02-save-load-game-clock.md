# S02 — 세이브/로드 + 게임 시계 (M0)

**선행**: S01 | **기획서 참조**: 22장(시간 시스템)

## 목표
이중 시간(자원/사건)의 뼈대와 저장 체계. 이후 모든 시스템이 이 시계에 구독으로 붙는다.

## In
- JSON 세이브/로드 (`Application.persistentDataPath`), 저장 스키마 버전 필드 (마이그레이션 대비)
- `GameClock`: 두 트랙 인터페이스 — 자원 시간(실시간 기반, 앱 종료 후에도 경과 계산), 사건 시간(앱 실행 중에만 tick)
- 게임 내 1일 = 현실 15분 사이클, 시각 구간 이벤트 (아침 06~09 / 낮 / 저녁 18~21 / 야간 21~06)
- 종료 시각 기록 + 재시작 시 오프라인 경과 시간 계산 훅 (**정산 로직 자체는 S08** — 여기선 "몇 초 지났는지"만 제공)
- 에디터 치트: 시간 배속 (경제/계절 검증에 계속 쓰임)

## Out
오프라인 보상 정산(S08), 계절/날씨(S11)

## 완료 기준
껐다 켜면 상태 복원 + 오프라인 경과 초가 정확히 나옴. 배속으로 게임 내 하루가 돌아감
