# A05 — UI 에셋 (아트 트랙)

**선행**: A01 승인 · **UI가 더 안 바뀔 때(S19~S20 폴리시 무렵)** 실행 권장
**규격**: CLAUDE.md 아트 규약

## 목표
코드로 생성하던 플레이스홀더 uGUI를 실제 픽셀 UI로 교체한다.

## In
- **패널·프레임**: 조합 창(가마솥)·도감·대화창·팝업. **A01 교훈 — 첫 시도(장식 화려한 조각 목재 + 켈트 매듭)는 32px 청키 맵과 시각 언어가 어긋났음. 더 단순·청키·저디테일로** 갈 것
- 버튼(기본/호버/비활성), 슬롯 프레임, 진행 바(성장·가공), 탭
- 아이콘: 골드·별빛 조각·시계·계절/날씨 표시
- 대화창: 화자 이름표 + 본문 영역 (초상 160px가 옆에 서는 구조 — 기획서 2-2장)
- 한글 폰트: 픽셀 한글 폰트 선정·임포트 (현재 레거시 Text + OS 폰트 폴백 상태 — TMP + 한글 픽셀 폰트로 교체)

## Out
캐릭터·아이템 아트(A03·A04), 지면(A02)

## 완료 기준
모든 창·버튼·바가 픽셀 UI로 교체되고 한글이 픽셀 폰트로 렌더링됨. 1920x1080·창모드에서 깨짐 없음
