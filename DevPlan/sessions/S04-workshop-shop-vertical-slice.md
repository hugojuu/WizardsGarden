# S04 — 공방 + 상점 → 수직 슬라이스 ★ (M1)

**선행**: S03 | **기획서 참조**: 2장(루프·3구역), 5장(1차 가공만), 8장(비용 곡선 공식)

## 목표
"심고 → 가공하고 → 팔아서 → 더 심는" 완전한 루프. **이 게임의 첫 재미 검증 지점.**

## In
- 공방: 작업대 1개, 1차 가공 (티어1 식물 → 마른 잎 4종, 가공 시간·가치 ×4~5)
- 상점: 진열대, 손님 방문 타이머, 판매 → 골드
- 성장 루프: 밭 슬롯 추가 구매 `Cost(n) = Base × 1.15^n`, 티어2 종자 해금 1개
- 골드/인벤토리 HUD

## Out
포션/조합(S05~S06), 자동화, 견습생
