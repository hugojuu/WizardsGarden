# A02 — 구역 배경·타일 (아트 트랙)

**선행**: A01 승인 완료 | **규격**: CLAUDE.md 아트 규약 (타일 32px · PPU 32 · lineless 부드러운 결 · 밝고 화사한 자연 녹색)

## 목표
맵의 지면을 플레이스홀더 색 사각형에서 실제 타일로 교체한다. 3구역(정원·공방·상점)이 한 화면에서 공간으로 구분되어 보이게.

## In
- **지면 타일셋**: A01 확정 잔디↔흙 타일셋을 기준으로, 연결 타일셋 체이닝(`lower_base_tile_id`)으로 이어붙일 것 — 잔디 → 흙(정원 밭) → 돌바닥(공방) → 나무바닥(상점)
- **구역 소품**: 작업대·가마솥(공방), 진열대·간판(상점), 밭 울타리·물통(정원) — `create_map_object`로, 스타일 일관성을 위해 `background_image`(기존 타일) 스타일 매칭 활용 권장
- 맵 경계·장식(나무·돌·꽃) 소량 — 숲작마풍 아늑함은 여백 장식에서 나옴
- Unity 배선: `MapScreen`의 플레이스홀더 생성부를 실제 스프라이트 참조로 교체 (색 사각형 → SpriteRenderer). 좌표 상수는 유지

## Out
캐릭터·유닛(A04), 식물·아이템 아이콘(A03), UI 프레임(A05)

## 완료 기준
맵 화면이 색 사각형 없이 타일·소품으로 채워지고, 3구역이 시각적으로 구분되며, S04b의 풀 루프가 그대로 동작 (스크린샷으로 확인)
