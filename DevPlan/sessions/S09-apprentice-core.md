# S09 — 견습생 유닛: 이동·작업 행동 + 코어 (M4)

**선행**: S08, S04b | **기획서 참조**: 2-2장(유닛 행동 — 자동화의 실체), 10장(직군·스탯·희귀도), 12장(성장 3축 중 레벨업만), 14장(일반 8명)

## 목표
자동화의 실체 — 견습생이 맵 위를 걸어다니며 실제로 일한다. "누구를 어디에 배치할까"가 눈에 보이는 선택이 된다.

## In
- **유닛 행동 시스템**: 대상 탐색 → 이동(그리드/직선 — 본격 경로 탐색은 필요해질 때) → 작업(시간 소요) → 운반 루프. 순수 C# 상태 기계 + MonoBehaviour 표시 어댑터
- **직군별 행동**: 정원사(심기·수확), 연금술사(가공 시작·수령), 점원(창고→진열 채우기). 자동화 효율(60/80/100%)과 스탯은 작업 속도·운반량·대기 시간으로 구현
- ApprenticeData 완성 + 런타임 상태(레벨·경험치·배치 구역), 배치 슬롯(구역별 — 보유 > 슬롯 설계), 레벨업(최대 20, 스탯 +1), 각성(10레벨 → 희귀도 상승)
- S08의 임시 자동화 상수를 **유닛 기반 정산으로 교체** (오프라인은 "유닛이 일한 셈" 결과 계산 — 2-2장)
- 일반 8명 데이터 + 플레이스홀더 유닛 표시(색+이모지), 유닛 클릭 = 상태 보기
- 세이브 확장 (버전 +1 + 마이그레이션)

## Out
패시브/영입/장비(S10), 친밀도·대사(S15~S16), 유닛 정식 아트·애니메이션(A04)

## 완료 기준
견습생을 정원에 배치하면 유닛이 걸어다니며 심고 수확하는 게 **눈에 보이고**, 배치 유무·스탯에 따라 처리량이 달라진다. 오프라인 정산도 유닛 기준으로 작동. 작업량이 커지면 S09b(스탯·각성 분리)로 쪼갠다 — 억지로 한 세션에 넣지 말 것
