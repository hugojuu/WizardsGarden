# S09 — 견습생 코어 (M4)

**선행**: S08 | **기획서 참조**: 10장(직군·스탯·희귀도), 12장(성장 3축 중 레벨업만), 14장(일반 8명)

## 목표
"누구를 어디에 배치할까"라는 선택의 무게 만들기.

## In
- ApprenticeData 완성 + 런타임 상태 (레벨, 경험치, 배치 위치)
- 배치 슬롯: 구역별 (초반 각 1 → 확장 구매), 보유 > 슬롯 설계
- S08의 임시 자동화 상수를 **배치 견습생 기반으로 교체** (직군별 효율: 정원사 60% / 연금술사 80% / 점원 100%, 스탯 반영)
- 레벨업 (최대 20, 스탯 +1), 각성 (10레벨 → 희귀도 상승)
- 일반 8명 데이터 입력 (봄이~씨드, 플레이스홀더 초상)

## Out
패시브/영입/장비(S10), 친밀도(S15), 대사(S16)

## 완료 기준
견습생 배치 여부·스탯에 따라 구역 효율이 눈에 보이게 달라짐. 오프라인 정산도 견습생 기반으로 작동
