# S15 — 친밀도·선물·대화 시스템 (M7)

**선행**: S10 (S11~S14와 병렬 가능) | **기획서 참조**: 19장(친밀도), 20장(선물), 12장(성장 3축)

## 목표
캐릭터 애착의 기계 부분 — 수동적 누적 + 능동적 순간의 이중 구조.

## In
- 친밀도 5단계 (점수 구간·해금: 호칭 변경/스탯 +2/패시브 슬롯 2/외형 변화 훅)
- 획득 경로 전부: 일하는 시간 (+5/h, 사건 시간), 선물 (취향 데이터 — 20장 표 + 신규 포션 연동 각주), 일일 대화 (+10, 1회), 이벤트 훅, 모험 동행 (+30, S13 연결), 마음의 묘약 (+300)
- 선물 UI (인벤토리에서 선택 → 반응 연출), 싫어함 -10 (가벼운 페널티)
- 판매/장비/선물 3중 트레이드오프가 이 세션에서 완성됨

## Out
스토리 챕터(S16), 대사 콘텐츠(S16~S18)

## 완료 기준
19·20장 수치대로 작동. 견습생 하나를 5단계까지 올리는 치트 테스트 통과
